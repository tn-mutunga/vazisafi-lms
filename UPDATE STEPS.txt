VAZI SAFI LMS v2.1.3
- Dashboard revenue now counts the value of orders taken (was only counting money received,
  so unpaid orders showed KES 0). Collected and unpaid amounts shown underneath.
- Net profit, Period summary, 14-day chart and Revenue vs Expenses use order totals.
- Reports > By service now uses real orders for the selected period (was demo figures).
- Mac updater: signs the app piece by piece (fixes "sign failed" since 2.1.0) and refuses
  to update when the disk has less than 2 GB free.

Publish (Mac Terminal):
cd ~/Documents/"Vazi Safi"/"Laundry Management System" && \
rsync -av ~/Downloads/vazisafi-lms-v2.1.3/ ./ && \
grep -q '"version": "2.1.3"' package.json && \
git add . && git commit -m "v2.1.3: revenue counts order value, real by-service report, Mac updater signing fix" && \
git push && git tag v2.1.3 && git push origin v2.1.3 && echo "PUSHED v2.1.3"

Windows shop PC: updates itself (update banner appears, click to restart).

Mac: the installed app cannot update itself this once. After GitHub finishes the build:
1. Free disk space first (need 5 GB+):  df -h /
2. rm -rf ~/Library/"Application Support"/"VaziSafi LMS"/pending-update
3. rm -rf "/Applications/VaziSafi LMS.app"
4. Download the 2.1.3 Mac zip from GitHub Releases, then:
   ditto -x -k ~/Downloads/<the-2.1.3-zip>.zip /Applications
   xattr -cr "/Applications/VaziSafi LMS.app"
   open "/Applications/VaziSafi LMS.app"
From 2.1.3 on, Mac updates install on their own.
