SYNC (the shop laptop's missing / late orders)
- One refused order no longer holds back the rest: the batch is retried one order at a time,
  the good ones go up, and Cloud & Updates names each refused order with the reason and fix.
- An order whose attendant or customer is not in the cloud yet still uploads (filled in later).
- New work goes up within about a minute (was: next 5-minute sync).
- Uploading no longer waits for an open window. The evening Closing check used to stop all
  uploads for as long as it was on screen.
- Only one sync runs at a time (button + timer no longer send everything twice).
- Top-right pill says "N orders waiting to send" until the cloud really has them; hover for the
  order numbers and the reason; tap it to send now.
- Cloud & Updates: refusals listed one per line, list of orders not in the cloud yet, and how full
  this laptop's storage is. If storage is ever full, a red warning now appears (it was silent).
