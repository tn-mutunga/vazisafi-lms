VAZI SAFI LMS v2.0.7 (includes 2.0.5 + 2.0.6)
Fix: "renderer-badge.js not found" at start-up.

1. Publish:
cd ~/Documents/"Vazi Safi"/"Laundry Management System"
rsync -av ~/Downloads/vazisafi-lms-v2.0.7/ ./
ls desktop/renderer-badge.js         (must exist)
grep '"version"' package.json        (should say 2.0.7)
git add . && git commit -m "v2.0.7: include renderer-badge.js, start-up never blocked" && git push && git tag v2.0.7 && git push origin v2.0.7

2. Wait for GitHub Actions to go green.

3. Mac (app cannot start, so install by hand once):
rm -rf "/Applications/VaziSafi LMS.app"
# download VaziSafi-LMS-2.0.7-arm64.dmg from GitHub Releases, then:
xattr -c ~/Downloads/VaziSafi-LMS-2.0.7-arm64.dmg
hdiutil attach ~/Downloads/VaziSafi-LMS-2.0.7-arm64.dmg -nobrowse -mountpoint /tmp/vazi
ditto --noextattr --noqtn "/tmp/vazi/VaziSafi LMS.app" "/Applications/VaziSafi LMS.app"
hdiutil detach /tmp/vazi
xattr -cr "/Applications/VaziSafi LMS.app" && codesign --force --deep --sign - "/Applications/VaziSafi LMS.app"
open "/Applications/VaziSafi LMS.app"
If "Not Opened": Done > System Settings > Privacy & Security > Open Anyway.

4. Windows: Install & restart when offered.
